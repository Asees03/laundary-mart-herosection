# Laundry Services Hero Section

## Project Description
A responsive laundry service landing page featuring a navigation
bar and a hero section designed using HTML and CSS.

## Features
- Navigation bar with Home, Services, About Us, and Contact Us.
- Logo on the left and user name on the right.
- Hero section with a heading and service description.
- Book a Service Today button.
- Laundry-related image.
- Customer statistics section.
- Responsive layout for smaller screens.

## Technologies Used
- HTML5
- CSS3

## Project Structure

Laundry-Services/
├── index.html
├── style.css
└── README.md

## How to Run
1. Keep index.html and style.css in the same folder.
2. Open index.html in a web browser.
3. Ensure you have an internet connection to load the laundry image.

## Layout Techniques
- display: inline-block
- CSS positioning and vertical alignment
- Viewport units (vh)
- Media queries
- Object-fit for image sizing
